# Pizza Sales Data Analysis (SQL)

## 📌 Project Overview
This project involves a comprehensive analysis of a pizza shop's sales data to extract actionable business insights. Using **MySQL**, I joined multiple tables and applied advanced analytical techniques to understand revenue trends and customer preferences.

## 🚀 Key Business Questions Answered
*   **Revenue Growth:** Tracked cumulative revenue over time to identify growth trends.
*   **Product Performance:** Identified the top 3 most ordered pizza types based on revenue.
*   **Category Analysis:** Calculated the percentage contribution of each pizza category to total sales.
*   **Order Patterns:** Analyzed daily order averages and category-wise distribution.

## 🛠️ Tech Stack & SQL Skills Used
*   **Tool:** MySQL
*   **Skills:** Multi-table Joins, Subqueries, Window Functions (`OVER`, `RANK`), Aggregate Functions (`SUM`, `AVG`), and Data Rounding.
